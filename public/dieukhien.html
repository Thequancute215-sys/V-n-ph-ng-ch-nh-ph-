Chờ duyệt chuyển lượt

Chạy tay từng lượt: AI xong thì in dòng JSON bàn giao, bấm "Duyệt chuyển lượt" thì ctl mới ghi agent.md và commit chore(agent-sync) trên máy này (không push). Tự động hoàn toàn: giao việc ở trang "Claude báo cáo & tự động" — ctl tự duyệt và chạy vai kế tiếp, dừng lại báo anh khi lượt lỗi, bàn giao sai, hết lượt/thời gian, Codex sửa quá 2 lần, xung đột git, log lộ khóa, hoặc Claude hỏi anh / báo cáo xong. Đủ 4 vai đều chạy nền: Antigravity (agy), Sol và Astra (codex), Claude (claude). Phanh khẩn cấp dừng cả luồng.

Chạy lệnh trong workspace đang chọn · không qua shell

Danh sách cho phép (chạy ngay): git status/diff/log/add/commit/fetch/pull --ff-only…, npm test/ci/run, node --test, node/python <script trong workspace>, pytest, python -m pytest/unittest, cargo/go test·build, gh … list/view. Lệnh khác (git push, npm install, xóa file…) vào hàng chờ duyệt. Shell (cmd, PowerShell, bash…) và python -c / python không đối số bị từ chối.
